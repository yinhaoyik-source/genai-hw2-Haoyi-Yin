# GenAI HW2 - Haoyi Yin

## Workflow
Drafting customer support email responses for common customer issues such as refunds, delays, and product problems.

## User
Customer support agents at an e-commerce company.

## Input
Customer messages describing issues such as damaged products, late deliveries, or refund requests.

## Output
A clear, polite, and professional email response that addresses the customer’s issue.

## Value
This task is valuable to automate because it is high-volume and repetitive, requires a consistent tone, and saves time for human agents while allowing them to focus on more complex cases.
